# Geometry

Консольное приложение на C++, демонстрирующее работу с геометрическими фигурами на базе абстрактных классов, механизмов динамического полиморфизма и базовой анимации с использованием многопоточных задержек.

## Архитектура ООП и Абстракция

Проект построен на принципах классификации объектов с использованием механизмов динамического полиморфизма:

1. **Абстрактный базовый класс (`Shape`):** Объявлен с ключевым словом `virtual` для деструктора. Класс описывает абстрактное понятие геометрической фигуры и содержит четыре **чистые виртуальные функции (Pure Virtual Functions)**, не имеющие реализации на базовом уровне:
   * `getArea() const = 0` — расчет площади фигуры.
   * `getPerimeter() const = 0` — расчет периметра.
   * `draw() const = 0` — отрисовка контура фигуры в консоли.
   * `printProperties() const = 0` — вывод технических характеристик.
2. **Конкретные дочерние классы:** `Square` (квадрат), `Rectangle` (прямоугольник), `Triangle` (треугольник) и `Circle` (круг) наследуют базовый класс `Shape`. Они обязаны переопределить все чистые виртуальные методы с ключевым словом `override`, чтобы стать конкретными классами и позволить создавать свои экземпляры в памяти.

## Полиморфный контейнер и Upcast

В функции `main` реализована концепция обобщения (Generalisation):
* **Единый контейнер объектов:** Создается массив указателей на базовый тип `Shape* shapes[4]`.
* **Приведение типов вверх (Upcast):** При записи в массив адресов динамически выделенных объектов `new Square()`, `new Rectangle()` и т.д., происходит автоматическое приведение дочерних объектов к базовому типу. Это позволяет хранить разнородные фигуры в одном месте.
* **Таблица виртуальных методов:** При переборе массива в цикле компилятор через указатели на виртуальные функции вызывает специфичные реализации методов `printProperties()` и `draw()` для каждой конкретной фигуры непосредственно во время выполнения программы.

## Консольная анимация и Потоки (std::thread)

Для визуализации отрисовки геометрии внутри базового класса `Shape` реализован защищенный метод `drawWithDelay`, использующий системные библиотеки `<thread>` и `<chrono>`:
* **Потоковая задержка:** Функция `this_thread::sleep_for(chrono::milliseconds(...))` приостанавливает выполнение текущего потока программы на заданное количество миллисекунд. Это создает эффект плавного «посимвольного» рисования контуров фигур (используется символ `$`).
* **Принудительный сброс буфера:** Для немедленного вывода символа на экран без ожидания заполнения всей строки консоли применяется манипулятор `std::flush` (`cout << symbol << flush`).

## Сборка и запуск

1. Откройте исходный код проекта в интегрированной среде разработки (например, Visual Studio).
2. Выберите конфигурацию проекта (**x86** или **x64**), которая определит разрядность указателей в массиве `shapes` (4 или 8 байт соответственно).
3. Программа последовательно для каждой фигуры выполнит расчет математических свойств, выведет их на экран, выдержит секундную паузу и отрисует анимированный контур объекта в консоли, после чего корректно освободит выделенную память через оператор `delete`.
